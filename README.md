# AppTreino
Web App de Treino. Inclui cronómetro de descanso com alerta sonoro, checkboxes modernos para marcar exercícios feitos e registo de cargas (pesos) que ficam guardados no telemóvel. Cada exercício tem um link direto para vídeos de execução no YouTube. Design Premium Dark, otimizado para usar como App no ecrã inicial.
